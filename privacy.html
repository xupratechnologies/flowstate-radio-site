Privacy Policy

Last updated: October 12, 2026

The FlowState Radio Music upload tool is a private application used only by the owner of the FlowState Radio Music YouTube channel. It is not offered to the public.

What data the tool accesses

The tool uses the YouTube Data API to upload videos to, schedule videos on, and read the upload list of the owner's own channel. It does not access any other user's data.

How data is stored

OAuth credentials are stored privately by the channel owner and are never shared, sold or transferred to third parties.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
